# Wasteoff 3D 편의점

참가자는 3D 편의점에서 마감 상품을 골라 주문하고, 같은 조건의 일반 판매와 폐기 수량, 정상가 판매, 점포 추정 이익을 비교할 수 있습니다.

## 실험 참여

1. 장보기 버튼에서 참가자 이름과 실험용 비밀번호를 등록합니다. 계정별 시작 예산은 10,000원이며, 이전에 적립된 500P를 사용할 수 있습니다.
2. 진열대의 상품을 누르거나 목록의 담기 버튼으로 장바구니를 채웁니다. 주문 금액이 남은 예산을 넘으면 결제할 수 없습니다.
3. 가상 결제 후 23:00까지 계산대에서 수령합니다. 마감까지 수령하지 않은 주문은 취소되어 예산과 사용한 포인트가 돌아옵니다.
4. 효과 비교에서 폐기, 정상가 판매, 추정 이익의 차이를 확인합니다. 마감 처리 후 결과를 CSV로 받을 수 있습니다.

계정, 예산 및 주문은 참여한 브라우저의 IndexedDB에 저장됩니다. 새로고침이나 로그아웃 후 같은 브라우저로 돌아와 이어갈 수 있습니다. 다른 기기의 기록은 독립적입니다. 참가자가 내보낸 CSV로 실험 기록을 모을 수 있습니다. 실험용 상품과 가상 예산을 사용합니다.

## 비교 방식

- 두 판매 방식에서 각 상품의 초기 재고와 15분 단위 일반 손님 수요는 같습니다. 일반 손님 수요는 실험 시나리오에서 정합니다.
- 마감 판매 추천 수량은 초기 판매 가능 재고에서 예상 정상가 판매량과 안전재고를 뺀 값입니다. 시나리오에서는 이 수량이 승인됐다고 가정합니다. 시간이 지나면 확보된 주문과 남은 정상가 수요를 반영해 판매 가능 수량을 갱신합니다.
- 참가자가 마감 상품을 주문하면 픽업까지 별도 확보합니다. 마감 수령은 추가 수요이며, 결제한 뒤 실제로 수령을 마친 가상 주문만 마감 판매로 집계합니다. 수요가 예측보다 많으면 마감 주문 때문에 정상가 판매량이 줄어드는 경우도 나타납니다.
- 적립은 수령 후 반영되며 가격의 30%와 1,000P 중 작은 값이 개당 상한입니다. 같은 날 받은 포인트는 이 실험에서 사용할 수 없습니다.
- 점포 추정 이익은 결제액에서 초기 재고 원가, 수령 후 적립 포인트 및 폐기 비용(개당 100원)을 뺀 값입니다. 1P를 1원으로 계산합니다.

실험 수치는 가상 수요와 재고에 따른 결과입니다. 실제 매장의 판매·폐기 효과는 현장 데이터로 검증해야 합니다.

## 개발 및 배포

Node.js 22 이상이 필요합니다.

```sh
npm ci
npm run dev
npm test
npm run build
```

`main`에 병합하면 GitHub Actions가 정적 빌드를 GitHub Pages에 배포합니다. WebGL을 사용할 수 없는 환경에서도 상품 목록을 통해 같은 실험에 참여할 수 있습니다.
