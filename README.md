# Wasteoff Mart

직접 걸어 다니는 한국어 3D 편의점 체험입니다. 가상 매장에서 참가자 계정으로 장을 보고, POS에서 바코드를 스캔해 결제한 뒤 마감 간편식의 폐기 변화를 비교할 수 있습니다.

## 체험하기

- **1인칭·3인칭** 버튼 또는 **V**로 시점을 전환합니다. 매장에서 **WASD** 또는 방향키로 걷고 마우스 드래그로 둘러봅니다. **E**나 화면 클릭으로 상품 또는 계산대를 선택합니다. Shift로 달리고, 3인칭에서 Q로 카메라 어깨를 바꿉니다. 터치 화면에서는 조이스틱으로 이동하면서 다른 손가락으로 시점을 돌릴 수 있습니다. 조작 메뉴에서 감도와 시야각을 바꾸거나 카메라 흔들림을 줄일 수 있습니다.
- **매장 안내**에서 원하는 진열대에 바로 갈 수 있습니다. WebGL을 쓸 수 없는 기기에서도 이 안내를 통해 구매할 수 있습니다.
- 참가자 계정을 만들면 가상 예산 10,000원과 사용 가능한 500P로 시작합니다. 계정·잔액·영수증은 참여한 브라우저에 저장됩니다. 이전 버전에 담은 마감 상품과 결제 기록도 이어집니다.
- 계산대에서 13자리 상품 코드를 직접 입력하거나 장바구니 상품을 하나씩 스캔합니다. 전 상품을 스캔한 뒤 카드 또는 현금으로 가상 결제합니다. 생수 2+1, 청포도 탄산수 1+1과 마감 상품 포인트는 계산 시 반영됩니다. 현금 결제는 받은 금액과 거스름돈을 표시합니다.
- 계산대의 거래 내역에서 영수증을 저장하거나 결제 승인을 취소할 수 있습니다. 취소 시 잔액, 포인트, 재고가 돌아옵니다. 마감 시간이 지난 임박 상품이나 셀프 코너에서 조리한 상품은 재입고할 수 없습니다.
- 결제한 도시락과 컵라면은 셀프 코너의 전자레인지와 온수기에서 준비할 수 있습니다. 창을 닫아도 준비가 계속됩니다. 화면의 매장 소리 버튼을 켜면 발걸음과 스캔, 결제음이 들립니다.

## 마감 판매 실험

‘운영·비교’에서 손님 수요 조건을 선택하고 시간을 15분씩 진행할 수 있습니다. 일반 간편식과 오늘 23:00에 판매를 종료하는 제품은 별도 재고로 집계됩니다. 23:00 이후 일반 상품 장보기는 계속 열려 있습니다.

두 비교군에 같은 초기 임박 간편식 재고와 일반 손님 수요를 적용합니다. 폐기 수량, 일반 수요의 실제 정상가 판매 수량, 추정 이익을 비교하고 결과를 CSV로 저장할 수 있습니다. 일반 진열대에서 산 상품은 결제·영수증·재고에는 반영되며, 임박 간편식의 마감 효과 비교 범위에는 포함되지 않습니다.

## 개발

Node.js 22.6 이상에서 실행합니다.

```sh
npm ci
npm run dev
npm test
npm run build
```

결제·POS·재고·수요는 브라우저 안에서 동작하는 가상 매장 시스템입니다. 상품 포장과 바닥·천장·금속·목재에는 프로젝트용으로 생성한 텍스처를 사용했습니다.
